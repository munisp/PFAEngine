# Content rating — IARC questionnaire answers (Play Console)

Category selected: **Finance** (utility/financial management app).

Expected result: **Everyone / PEGI 3** (no age-restricted content; the product
itself is for adults 18+, declared separately under Target Audience).

| Question | Answer | Notes |
|---|---|---|
| Violence, blood, gore | No | — |
| Sexual content / nudity | No | — |
| Profanity / crude humour | No | — |
| Drugs, alcohol, tobacco references | No | — |
| Gambling (real or simulated) | **No** | Pension fund values are shown, but there is no staking, betting, or casino mechanics. Do **not** confuse "fund performance" with gambling in the form. |
| User-generated content / user-to-user communication | **No** | Support requests go to the PFA's member-care team (business-to-user), not user-to-user. If in-app chat with other members is ever added, re-answer and add moderation tooling. |
| Sharing of personal information with others | No | Data shared only with the operating PFA and as required by PenCom/regulators — declared in Data safety, not here. |
| Location sharing | No | Location is not collected or shared. |
| Purchases / digital goods | No in-app purchases | Contributions are pension remittances to the member's own regulated RSA, not digital goods; declare payments flow in the Financial features declaration instead. |
| Web content (app shows web views) | Yes — first-party only | TWA renders the PFA's own member portal over HTTPS; no unfiltered third-party web browsing. |

Post-questionnaire: verify the issued rating is Everyone / PEGI 3 (or regional
equivalent). Anything higher for a pension utility indicates a mis-answered
question — most commonly the gambling or UGC items.

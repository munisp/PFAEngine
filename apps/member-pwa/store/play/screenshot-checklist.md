# Screenshot checklist (Google Play)

Minimum 2 screenshots; target **8** (max per listing). Phone screenshots,
9:16 or 16:9, min 320px / max 3840px on the long edge. Capture on a
mid-range Android device profile (e.g. 1080×2400) — matches the target
audience's devices. Use the TWA build (no browser chrome) with realistic
demo data, never real member data.

Order matters — first two are shown in search results:

1. [ ] Dashboard — RSA balance + contribution growth sparkline ("know your
       balance at a glance")
2. [ ] Statement — QR-verifiable statement preview ("statements anyone can
       verify")
3. [ ] I-Am-Alive — selfie-liveness flow ("verify from home, skip the branch")
4. [ ] Contributions / voluntary top-up screen ("top up your pension anytime")
5. [ ] Funds — Fund I–IV performance chart ("see how your fund performs")
6. [ ] Claims / retirement booking ("start and track claims in-app")
7. [ ] Offline mode — last-known balance with offline indicator visible
       ("works on patchy networks")
8. [ ] Learn — pension literacy articles ("understand your pension")

Per screenshot:

- [ ] Status bar clean (full battery, no notifications, demo time)
- [ ] Caption text overlaid (short, ≤ 6 words, high contrast) — optional but
      strongly recommended
- [ ] No competitor names, no Play/App Store badges inside the image
- [ ] Naira amounts formatted ₦ with thousands separators, realistic values
- [ ] Consistent device frame and brand colours (#f7f4ee background family)

Also prepare (same captures reused):

- [ ] 7-inch tablet screenshot (optional but improves tablet placement)
- [ ] 10-inch tablet screenshot (optional)
